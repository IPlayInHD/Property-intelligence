# PropIQ — Apollo.io Cold Outreach Sequences

## How to Use This in Apollo

1. Go to **Sequences** → New Sequence
2. Create one sequence per persona below
3. Connect your Gmail/Outlook under **Settings → Mailboxes**
4. Use the **Apollo People Search filters** listed under each persona to build your lead list
5. Enroll leads directly into the sequence
6. Set daily send limit to **50–80/day** to protect deliverability

> **Sending domain tip:** Use a subdomain alias like `outreach@mail.propiq.com` (not your main domain) so spam hits don't affect your primary domain reputation. Apollo handles this — set it up under Settings → Email Deliverability.

## Apollo Setup Checklist

- [ ] Create 4 sequences (one per persona above)
- [ ] Set delay between emails: 3–7 days (as specified above)
- [ ] Set daily send cap: 50–80 emails/day per mailbox
- [ ] Enable auto-stop on reply (Apollo does this by default)
- [ ] A/B test subject lines — Apollo shows open rate per variant after ~50 sends
- [ ] Use a sending alias (not your primary domain)
- [ ] Set up a simple landing page reply (propiq.ai — already built)
- [ ] Check Apollo's "Email Grader" on each email before activating

## What to Track (Apollo Dashboard)

| Metric | Target |
|--------|--------|
| Open rate | > 40% |
| Reply rate | > 8% |
| Positive reply rate | > 3% |
| Waitlist conversion from email | > 15% of replies |

If open rate is below 30%, the subject line is failing — test new variants.
If reply rate is below 5%, the body copy isn't landing — shorten it further.
